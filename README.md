## 🗂️ Estrutura do repositório

As atividades estão organizadas **por tema**, e cada exercício fica em sua própria pasta com o arquivo `main.c`.

```
Algoritimos-em-C/
│
├── e_condicionais/          # Estruturas condicionais (4 atividades)
│   ├── atv1/
│   │   └── main.c
│   ├── atv2/
│   ├── atv3/
│   └── atv4/
│
├── l_repeticao/             # Laços de repetição (4 atividades)
│   ├── atv1/
│   │   └── main.c
│   ├── atv2/
│   ├── atv3/
│   └── atv4/
│
├── funcoes/                 # Funções (12 atividades + atividade em sala)
│   ├── atv1/
│   │   └── main.c
│   ├── ...
│   ├── atv12/
│   └── atv_em_sala/
│       └── main.c
│
└── README.md
```

| Tema | Pasta | Nº de atividades |
|------|-------|:----------------:|
| Estruturas condicionais | `e_condicionais/` | 4 |
| Estruturas de repetição | `l_repeticao/` | 4 |
| Funções | `funcoes/` | 12 + 1 em sala |

## ▶️ Como compilar e executar

Certifique-se de ter o **GCC** instalado e, a partir da raiz do repositório, execute:

```bash
# Exemplo: atividade 1 de funções
gcc funcoes/atv1/main.c -o atv1
./atv1
```

No Windows, o executável gerado pode ser rodado com `atv1.exe`.
